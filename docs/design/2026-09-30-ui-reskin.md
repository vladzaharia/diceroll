# UI reskin: Cartoony UI pack + Vector icons (DRAFT, in progress)

> Early draft so the area planners can align. The final version replaces this file.

## Direction (decided)
- **"Night navy + wood" (option D).** Modal frames = `Frames/Nailed` darkbrown (wood board with nails), with the hole baked-filled with `UiPalette.NAVY_2`-ish navy. Text palette stays light-on-navy, so UiPalette text colours barely change.
- **Buttons = 3D Square, 2.5 aspect** (`Buttons/3D/Square/<colour>/button-square-3d-2.5-<colour>-regular_<state>.svg`). Primary = yellow-regular, secondary = blue-regular, danger = red-regular, success = green-regular, disabled = grey-regular. Icon-only = `Buttons/3D/Round/.../button-round-3d-1-*`. Chips/pills = `Buttons/Flat/Round/.../button-round-flat-2.5-*`.
- **Title ribbon** = a 3D square 2.5 yellow button asset used as a plaque overlapping the frame top.
- **Cards** = `Containers/3D/0. White/container-3d-white.svg` modulated to NAVY_3 (selected: yellow frame Thin overlay).
- **Tooltips** = `Frames/Thin` darkbrown, navy fill.
- **Bars** = `Bars/Regular` container grey-darker + bar colour (HP red, XP purple, block blue, mastery yellow).
- **Icons** = the `<Name> Outline.svg` full-colour variant everywhere by default; `<Name> Flat White.svg` + modulate only for tinted glyphs (<= 24 px, status pips, input-less contexts). SVG only.
- **SVG over PNG** always. Pack paths are relative to `third_party/`.
